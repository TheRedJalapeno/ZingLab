HotGato Speed Reader brings the core HotGato experience into your browser with a lightweight extension for Chrome and Firefox. Select text on any page, right-click (or use the toolbar), and launch a focused reading session without leaving the page.

Supported browsers
- Google Chrome (Chrome Web Store)
- Mozilla Firefox (addons.mozilla.org)

Quick features
- Launch from context menu: select text, right-click, and choose HotGato Speed Read.
- Toolbar shortcut: open the extension UI and paste or load the current page text.
- Adjustable WPM, chunk size, and punctuation pause settings per-session.
- Bionic reading toggle for in-extension emphasis.
- Keyboard shortcuts for play/pause, faster/slower, and skip-forward/back.
- Works offline once installed — no external servers required for core reading features.

How to use
1. Install the extension from the Web Store or addons site linked above.
2. Select the text you want to read on any article or page.
3. Right-click and choose "HotGato Speed Read", or open the extension and paste text.
4. Set your WPM and chunk size, toggle bionic reading if desired, and press Start.

Settings you'll love
- Words-per-minute slider with +/- step controls for instant tuning.
- Chunk size control (1–5+ words) to find your ideal RSVP rhythm.
- Punctuation pause multiplier to lengthen pauses at commas, periods, and paragraph breaks.
- Option to preserve minimal inline styling or strip formatting for a cleaner reading view.

Privacy & permissions
The extension requests minimal permissions necessary to read selected page text and present it in the extension UI. Core reading functions run locally in the browser; no text is sent to external servers unless you explicitly use a sharing or sync feature. For enterprise deployments, we can provide hardened builds or policies that limit extension behavior.

Enterprise & distribution
- Packaged installer and group policy options are available for managed deployments.
- Corporate licenses include priority support and customization (branding, telemetry options, analytics integrations).

Tips
- For long articles, try a quick 100–200 WPM boost for the first pass, then drop down for a second careful read.
- If comprehension drops, reduce chunk size or enable punctuation pauses.
